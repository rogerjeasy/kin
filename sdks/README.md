# Kin API SDKs

TypeScript and Python SDKs for Kin's API, generated by [APIMatic](https://www.apimatic.io) from the OpenAPI document the server publishes at `/api/v1/openapi.json` (copied here as `openapi.json`). The document is built from the same schemas the server checks requests against, so the SDKs cannot drift from the API.

Regenerate them with one command (needs `APIMATIC_AUTH_KEY` in the root `.env`):

```bash
pnpm --filter @kin/web run sdk:generate            # from the hosted app
pnpm --filter @kin/web run sdk:generate http://localhost:3000
```

## Report a visit from an agency's software

An agency's request is signed: `Kin-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256(secret, "<t>.<raw body>")>`, with the key ID in `Kin-Agency-Key`. The organizer creates the key on **Circle → Connected assistants**. Sign exactly the bytes the SDK sends. Both examples below were run against the hosted app on 12 November 2026: TypeScript got `201` and Python got `received`.

**TypeScript** (`sdks/typescript`, `npm install && npm run build`):

```ts
import { createHmac } from "node:crypto";
import { ApiController, Client, Environment } from "kin-apilib";

const body = { externalId: "visit-1042", caregiver: "Amara", kind: "aide", startsAt: "2026-11-11T09:00:00-05:00", endsAt: "2026-11-11T13:00:00-05:00" };
const t = Math.floor(Date.now() / 1000);
const v1 = createHmac("sha256", process.env.KIN_AGENCY_SECRET!).update(`${t}.${JSON.stringify(body)}`).digest("hex");
const client = new Client({
  environment: Environment.Production,
  agencyKeyCredentials: { "Kin-Agency-Key": process.env.KIN_AGENCY_KEY_ID! },
  agencySignatureCredentials: { "Kin-Signature": `t=${t},v1=${v1}` },
});
const { result } = await new ApiController(client).reportVisit(body); // { status: "received", ... }
```

**Python** (`sdks/python`, `pip install ./sdks/python`):

```python
import hashlib, hmac, os, time
from kinapi.api_helper import APIHelper
from kinapi.http.auth.agency_key import AgencyKeyCredentials
from kinapi.http.auth.agency_signature import AgencySignatureCredentials
from kinapi.kinapi_client import KinapiClient
from kinapi.models.visit_report import VisitReport

report = VisitReport.from_dictionary({"externalId": "visit-1042", "caregiver": "Amara", "kind": "aide",
                                      "startsAt": "2026-11-11T09:00:00-05:00", "endsAt": "2026-11-11T13:00:00-05:00"})
t = int(time.time())
v1 = hmac.new(os.environ["KIN_AGENCY_SECRET"].encode(), f"{t}.{APIHelper.json_serialize(report)}".encode(), hashlib.sha256).hexdigest()
client = KinapiClient(agency_key_credentials=AgencyKeyCredentials(kin_agency_key=os.environ["KIN_AGENCY_KEY_ID"]),
                      agency_signature_credentials=AgencySignatureCredentials(kin_signature=f"t={t},v1={v1}"))
receipt = client.client.report_visit(report)  # receipt.status == "received"
```

A report is evidence beside the family's calendar. It pays nothing: every payment waits for a person in Kin.
